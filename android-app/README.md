# Proactive Safety Android App

This is the real device-first version of the project.

It uses Android location services and app-to-app cooperative sharing to:

- read live GPS position
- estimate current speed from device location
- send this phone's live position, speed, heading, and timestamp to your backend
- receive warnings when another app user may enter the same conflict area
- keep a live heartbeat so stopped phones remain visible to other app users
- compare the user against known high-risk road zones
- calculate a local risk score on the phone
- warn through notification, vibration, and text-to-speech
- provide an SOS emergency action

## Important Reality Check

A phone can know the speed/location of an opposite vehicle when that vehicle is also using this app.

The cooperative flow is:

```text
Phone A -> backend: GPS, speed, heading
Phone B -> backend: GPS, speed, heading
Backend -> both phones: conflict warning if their paths/junction ETAs are unsafe
```

For non-app vehicles, a phone alone cannot reliably detect opposite vehicle speed unless one of these is added:

- camera/computer-vision detection
- connected vehicle data
- roadside camera/radar data
- traffic authority API
- vehicle sensor integration

This Android app is the correct safety foundation: cooperative app users first, non-app vehicle detection later.

## Run Cooperative Backend

From the project root:

```text
npm start
```

On the Android app, set the backend URL to your laptop IP:

```text
http://192.168.0.149:3000
```

Both phones must use the same backend URL and be on the same network only for local laptop testing. Keep phone Location/GPS turned on.

For real use, deploy the backend to cloud and use the public `https://...` URL in the app. See `../CLOUD_DEPLOY.md`.

## Real Map

The APK uses real OpenStreetMap tiles and the phone's actual GPS location. Other app users appear on the map when the backend returns their live coordinates.

## Build APK

Open this `android-app` folder in Android Studio.

Then use:

```text
Build > Build Bundle(s) / APK(s) > Build APK(s)
```

The APK will be generated by Android Studio under:

```text
android-app/app/build/outputs/apk/debug/
```

## Test On Phone

1. Install the APK on Android.
2. Allow location permission.
3. Allow notifications.
4. Tap `Start GPS Monitoring`.
5. Install the app on a second Android phone.
6. Set the same backend URL on both phones.
7. Move both phones toward the same road/junction or path.
8. The backend calculates app-to-app path/junction conflict and warns both users.

The first configured high-risk zone is:

```text
Highway Cross Junction A
Latitude: 10.0154
Longitude: 76.3419
```
